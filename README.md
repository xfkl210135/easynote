# EasyNote

EasyNote 现已使用 Vue 3、TypeScript 和 Vite 构建。桌面端继续使用原有的本地优先 IndexedDB，手机端可直接通过现代浏览器访问；PWA 安装是可选能力，不需要安装 Android 或 iOS 原生应用。

## 开发与构建

需要 Node.js 20 或更高版本：

```powershell
npm install
npm run dev
```

开发服务器默认监听 `http://localhost:4173/`。生产构建、类型检查和测试：

```powershell
npm run build
npm test
npm run test:e2e
```

`npm run build` 会把可部署文件写入 `dist/`。双击 `start-easynote.bat` 仍会使用固定的 `http://localhost:4173/`，从而继续读取该来源下的现有 IndexedDB；如果生产构建不存在，启动脚本会先自动构建。

## 手机网页与部署

把 `dist/` 中的全部文件部署到支持 HTTPS 的静态网站即可。`index.html` 和 Service Worker 应使用短缓存或不缓存，`assets/` 与 `icons/` 可以长期缓存。首次在线打开成功后，页面可以离线重新启动。

- 手机端以现代 Chrome 响应式网页为本轮自动化回归基准；iPhone Safari 暂不列入本轮兼容性验收。
- 页面不提供原生应用安装入口；如用户自行通过浏览器“添加到主屏幕”，仍可作为普通 PWA 使用。
- 每个浏览器的数据仍独立保存在本机；本阶段不包含账号或多设备自动同步。
- 手机浏览器不支持目录选择时，数据安全中心会保留便携 JSON 导入导出，并隐藏自动目录备份按钮。
- 从其他域名或其他设备首次使用时，请通过便携 JSON 导入现有数据。

生产部署必须保持同一域名和 HTTPS。更换域名会得到新的浏览器存储空间，旧数据不会自动迁移。

## 时间与规划中心

一级导航仍保持“笔记、任务、日程、白板”。“日程”内部现已升级为时间与规划中心：

- 今日工作台支持以选中日为中心的前后三天、列表/30 分钟时间线、全天安排和移动端横向滑动切换日期。
- 日程与固定日程可关联任务、笔记和 HTTP/HTTPS 网址，并提供跳转、计时和失效关联提示。
- 固定日程支持每天、工作日、按星期和按月重复。
- 全局专注计时支持暂停、刷新续算、手动开始休息，以及专注完成后标记关联事项完成。
- 每日、每周、每月复盘会在保存时固化任务、日程和专注统计快照。
- 长期规划使用“目标 → 里程碑 → 关联任务”，支持自动加权进度或手动进度。

计时和日程提醒在页面或已启动的 PWA 中可使用站内提示，并根据授权使用声音、振动和系统通知。浏览器或 PWA 完全关闭后不保证准点通知。

本版本把 `easynote-db` 从版本 7 升级到版本 8，新增 `focusSessions`、`reviews`、`goals` 和 `milestones` 仓库。升级前会先在旧数据库中写入完整恢复记录，升级成功后再写完成标记；无法建立恢复记录时会停止升级。升级后的同一浏览器数据库不能再由旧静态版直接打开，回退请使用升级前恢复记录或便携 JSON。

便携备份仍是 `easynote-portable` v8，目录备份仍是 v6；新增数组作为可选扩展写入，因此旧备份可以导入，新功能数据也会进入新备份。

一个本地优先的个人笔记网页，无需安装依赖或启动后端。

## 使用方式

正式记录笔记时请双击 `start-easynote.bat`，浏览器会固定打开 `http://localhost:4173/`。

也可以运行 `create-desktop-shortcut.bat`，在 Windows 桌面创建 `EasyNote` 一键启动快捷方式。

本地服务只监听当前电脑，不会把笔记发布到局域网或互联网。首次从旧版迁移时：

1. 先双击 `index.html`，通过页面顶部提示导出迁移备份。
2. 双击 `start-easynote.bat`。
3. 在 localhost 页面导入 JSON，再到“数据安全”中选择备份目录。
4. 确认数据库、持久存储和目录备份均正常后开始大量记录。

旧 `file://` 来源中的 IndexedDB 不会自动删除，可作为迁移期间的额外保护。

## 已实现

- 三栏式笔记界面、拖拽调宽、独立隐藏和专注模式
- 新建、编辑、搜索、标签和收藏
- 可无限嵌套的文件夹树，文件夹下可包含多个笔记，并支持拖拽移动
- 回收站、恢复和永久删除
- 富文本与 Markdown 编辑模式
- 针对正文、图片、笔记和分类的分区域右键菜单
- 本地图片选择、粘贴与拖拽插入；图片支持文字环绕、多图并排、连续水平定位和段落间移动，并可分别调整宽度与高度
- 本地文件可上传到指定文件夹；PDF、图片、文本、Markdown 和 JSON 可直接查看，其他格式可保存和下载
- 正文链接默认在笔记主栏内打开，可通过查看器按钮、右键菜单或 `Ctrl/⌘ + 单击`改为新标签页打开
- 双笔记左右分栏，可从笔记右键菜单在右侧打开并拖动分栏线
- 根据 H1、H2、H3 自动生成笔记大纲，点击即可跳转
- 个人任务管理表与同步看板，支持行内快捷新建、分组、折叠、筛选、多条件排序、跨列拖拽和右侧详情
- 九种可自定义任务字段：文本、单选、多选、数字/进度、日期、复选框、链接、附件和关联笔记
- 任务字段可重命名、排序、隐藏、拖拽调宽和安全转换类型；进度滑条支持分段颜色并与状态智能联动
- 任务行、单元格、字段、分组和看板卡片提供对应的分区域右键菜单
- 五页签时间与规划中心：今日、总日程、固定日程、复盘和长期规划
- 固定日程按规则实时计算每天、工作日、每周和每月安排；日程支持任务、笔记、网址和专注计时关联
- 自动日程提醒支持开始、结束、全天上午/晚间及自定义时间；删除前写入 30 天恢复记录
- 任务详情可直接“安排到日程”或启动专注计时
- 多白板知识画布：文本、笔记、任务、图片、网页和分组卡片，支持拖拽、缩放、平移、网格吸附与内容搜索
- 白板文本卡片支持原地直接编辑；笔记卡片可滚动查看格式化正文，并可双击进入原笔记
- 白板卡片支持多选、缩放、换色、复制、层级调整、撤销重做；卡片间可创建带方向的连线
- 白板空白处、卡片、分组和连线提供对应右键菜单，常用操作会显示在所选内容附近
- 笔记与任务卡片实时读取来源内容并可跳转，图片复用附件去重存储，白板整体进入备份、校验和 30 天紧急恢复
- 新建、重命名和删除等输入/确认操作使用页面中央弹窗
- 笔记、任务、日程、白板、任务字段、视图和附件等独立存储的 IndexedDB 安全数据库及旧数据迁移
- 串行写入、回读校验、真实保存失败状态和启动完整性检查
- 50 个/30 天笔记历史及永久删除后的 30 天紧急恢复
- 浏览器持久存储、容量监控和本地目录多代自动备份
- 深色模式
- JSON 整体备份/恢复与 Markdown 单篇导入导出
- 快捷键：`Ctrl+N` 新建、`Ctrl+K` 搜索、`Ctrl+S` 保存、白板内 `Ctrl+Z/Y` 撤销重做、`Ctrl+Shift+F` 专注模式

> 只有写入完成并回读校验通过后，页面才会显示“已验证保存”。自动目录备份暂不加密，请选择受 Windows 账户保护且空间充足的可靠磁盘。清理浏览器站点数据前，请确认数据安全中心显示最近目录备份正常。

浏览器、磁盘和操作系统都无法提供绝对零风险保证。特别重要的资料，建议再使用系统备份工具把 `EasyNote-Backups` 目录复制到另一块磁盘。

单个本地文件上限为 25MB。由于页面完全离线运行，Word、Excel、PPT、压缩包等格式暂不解析内容，但可以保存在文件夹中并下载。
